# V19 Knowledge Workspace UX + Data Profiles

- Files and system operations are now separated into focused right-rail tabs.
- The default Files view contains a calmer upload flow, file search/filter, compact file cards, and a clear upload result.
- System functions are still available in accordions, but do not crowd the upload/file workflow.
- Every new PDF/Excel/CSV gets a locally generated `data_profile` showing storage target, data shape, searchable content, numeric highlights, and suggested questions.
- File pages now use Overview, Data table, and AI notes tabs.
- Existing files receive a frontend fallback profile; re-upload to persist a backend profile.
