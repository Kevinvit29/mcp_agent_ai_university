# Admin Normal ChatGPT Mode + University Database

This version makes admin behave like a normal ChatGPT-style assistant first, with university database tools added on top.

Admin can ask normal text questions such as:
- explain machine learning
- fix this grammar
- write an email
- create code
- solve math
- translate text
- brainstorm lesson ideas

Admin can also ask university database questions such as:
- list all students
- give me S001 profile
- what files are uploaded?
- summarize everything in the university system

Important: this project uses the OpenAI / ChatGPT API for general knowledge and reasoning, but it still does not include live web search. To answer real-time news, prices, regulations, or current facts, add a web-search API/tool.
